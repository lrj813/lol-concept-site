# 掌上英雄联盟 · 服务体验概念站

一个以“召唤师的一局游戏旅程”为主线的静态网页概念项目。它保留黑金、国风、画卷式的视觉语言，并用更清晰的导航与交互组织战绩、资讯、赛事、英雄资料、攻略和下载入口。

> 这是非官方、非商业的产品与视觉设计演示，不隶属于或代表 Riot Games、腾讯、英雄联盟或掌上英雄联盟。页面中的资讯、赛程、榜单和活动为演示内容；真实信息请以官方渠道为准。

## 已完成的优化

- 按用户任务重构导航：首页、功能、资讯、赛事、英雄、下载。
- 将原先造成大段空白的强制横向滚动，替换为可拖动、可点击、支持滚动捕捉的功能画卷。
- 为导航、英雄筛选、资讯专题和功能画卷补充键盘操作、焦点语义和减少动态效果支持。
- 移除容易被误认为实时官方信息的静态赛事与新闻数据，明确标识为演示内容。
- 下载区域保留至官方页面的跳转入口；本项目不收集账号、战绩或任何用户数据。

## 本地预览

这是零构建依赖的静态站点。直接打开 `index.html`，或在仓库根目录启动任意静态 HTTP 服务后访问即可。

```bash
python3 -m http.server 8080
```

## 部署

仓库包含 GitHub Pages Actions 工作流。将默认分支推送到 GitHub，并在仓库 **Settings → Pages** 中选择 **GitHub Actions** 作为发布源后，页面会自动部署。
